Server Status

Checking server…

TheRavensCall runs a built-in web server on port 2112 on the game server. No external app needed.

If the status shows Offline:

  • Make sure the dedicated server process is running
  • Check BepInEx console for any mod errors
  • Confirm TheRavensCall.dll is in BepInEx/plugins/

Connecting from Phone or Tablet

Connect your phone to the same WiFi as your gaming PC, then open:

Finding your local IP…

Can't reach it? Find your PC's IP manually:

  • Open Command Prompt and type ipconfig
  • Look for IPv4 Address under your WiFi adapter
  • Open http://192.168.x.x:2112 on your phone

⚠ Use http:// not https — type it manually if your browser auto-corrects.

Windows Firewall

The first time the mod runs, Windows may show a firewall prompt. You must click Allow for other devices to connect.

If you missed it or phone access isn't working:

  • Open Windows Defender Firewall → Allow an app through firewall
  • Find valheim_server.exe and check both Private and Public
  • Or run this in PowerShell as Admin:
netsh advfirewall firewall add rule name="Valheim TheRavensCall" dir=in action=allow protocol=TCP localport=2112

Only needed for phone/tablet access — localhost always works without firewall changes.
