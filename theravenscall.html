Connection help
The dashboard talks to this mod's own HTTP server, normally http://localhost:2112 on the machine running the server. It only listens on that machine unless the server owner turns on HttpBindAllInterfaces — reaching it from another device needs that, plus the network/firewall path to the port.
If HttpApiToken is set on the server, this page needs the same value entered in Settings (gear icon above) before /api/state will load — a 401 opens Settings automatically.
Feedback: github.com/RavenIron-Games/TheRavensCall/issues
